# Reference library

Rule text the app checks, kept short. Each file names its source and the date it was current.

- [health-warning.md](health-warning.md) — 27 CFR 16.21 warning text, verbatim, and 16.22 format rules.
- [label-elements.md](label-elements.md) — mandatory label elements for wine, spirits and malt
  beverages (27 CFR parts 4, 5, 7): placement, alcohol and net-contents formats, name and address,
  country of origin.
- [accessibility.md](accessibility.md) — the WCAG 2.0 A and AA criteria the UI must meet, why
  Section 508 names that level, and which later criteria are built above it without being claimed.

TTB's Beverage Alcohol Manual is not included: TTB marks its spirits and malt beverage volumes as
not updated for the current regulations. TTB guidance that qualifies a rule sits beside that rule;
there is no separate guidance file.
