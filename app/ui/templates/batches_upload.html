Bulk label upload

Pick multiple PNG or JPEG files. Each becomes one label in a single batch; the streaming results page opens once the worker spawns.

Don’t have label images? Download a 10-label sample pulled from the TTB Public COLA Registry (CC0). Unzip and drop into the file picker below to exercise the full pipeline.

A bulk upload carries images and no applications, so nothing is compared against one. The beverage type still decides which rules apply: a wine label checked against the spirits rules fires none of the wine rules. To compare a label against its application, submit it on the single-label page.
