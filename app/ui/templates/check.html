The label photographs (PNG or JPEG)

A COLA is filed with every face of the label and the mandatory elements are spread across them — the government warning is usually printed on the back — so send every face you have. A front on its own is still a whole submission, and the check is then honestly a check of what you showed: the warning is reported missing because it is not on the photograph.

Leave that unticked and each image is its own label, unless two are named anything-front.jpg and anything-back.jpg — same stem, different suffix — in which case they are checked together as one label.

Don’t have label images? Download a 10-label sample pulled from the TTB Public COLA Registry (CC0), with the applications filed for them in applications.csv. Unzip it and select everything — images and CSV together — in the picker above. Its files are already named for pairing, so the labels that have two faces arrive as two faces.

The application filed for this label

The check compares the label against the application. Fill in what the application declares; a field left empty is not checked, and the label is still checked for what every label must carry.

Uploading more than one label? These typed fields describe one label, so only the beverage type is used — it decides which rule pack runs at all. Send the rest as a CSV below, one row per label.

The applications, as a CSV, for more than one label

One row per label. The first column is the image filename — 26230001000420 matches both 26230001000420-front.jpg and its back — and the rest are the ten application fields: beverage_type, brand_name, fanciful_name, class_type, alcohol_content, net_contents, applicant_name_address, source_of_product, origin, wine_appellation. A blank cell means the application declared nothing for that element, and the check against it reports that it does not apply.

A label the CSV has no row for is still read and still checked for what every label must carry, and its result says nothing was compared. The beverage type above applies to those labels.
